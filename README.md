# Nordec Laboratory Information Management System (LIMS)

نظام إدارة معلومات المعمل لمعمل **Nordec** لزيوت التشحيم.

مصمم ليتوافق مع متطلبات **ISO/IEC 17025:2017**.

## الميزات الرئيسية

- **تسجيل العينات** مع بيانات السحب الكاملة (Sampling data) حسب بند 7.3
- **مكتبة اختبارات** شاملة لزيوت التشحيم (Viscosity, TAN, TBN, Wear Metals, FTIR, Water, Flash Point...)
- **إدارة المنتجات والمواصفات** (حدود القبول Min/Max)
- **إدخال النتائج** مع حساب المطابقة التلقائي (Pass / Fail)
- **توليد شهادة التحليل (COA)** أوتوماتيك بصيغة PDF احترافية
- **سجل تدقيق (Audit Log)** لكل العمليات
- **تقارير وتصدير** Excel

## التشغيل

```bash
cd nordec_lims
streamlit run app.py
```

ثم افتح المتصفح على الرابط الذي يظهر (عادة http://localhost:8501)

## هيكل الملفات

- `app.py` : التطبيق الرئيسي (Streamlit)
- `database.py` : قاعدة البيانات SQLite + تهيئة البيانات
- `coa_generator.py` : توليد شهادات التحليل PDF
- قاعدة البيانات تُحفظ في `/tmp/nordec_lab.db`

## ملاحظات للتوافق مع ISO 17025

1. النظام يسجل كل إجراء في Audit Log.
2. بيانات أخذ العينات كاملة.
3. النتائج مرتبطة بالمحلل والتاريخ والطريقة.
4. حكم المطابقة واضح.
5. شهادات التحليل تحتوي على البيانات الإلزامية (بند 7.8).
6. **مهم**: قبل الاعتماد الرسمي يجب عمل Validation للنظام (بند 7.11).

## التطوير المستقبلي المقترح

- صلاحيات مستخدمين كاملة + تسجيل دخول
- ربط الأجهزة (Instrument integration)
- حساب Uncertainty
- Control Charts / QC samples
- إشعارات وتنبيهات
- واجهة عربية كاملة + دعم RTL أفضل
- نسخ احتياطي تلقائي
